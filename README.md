# Бот-ассистент для Яндекс Практикума

VK-бот для автоматического отслеживания статусов домашних работ в Яндекс Практикуме.

## Описание проекта

Бот обращается к API сервиса Практикум Домашка каждые 10 минут и проверяет изменения статусов отправленных на ревью работ.

При появлении нового статуса бот отправляет уведомление пользователю во ВКонтакте.

Возможные статусы:
- `reviewing` — работа взята на проверку.
- `approved` — работа принята ревьюером.
- `rejected` — работа возвращена на доработку.

Программа также ведёт журнал событий, обрабатывает ошибки API и отправляет уведомления о сбоях, избегая повторных сообщений об одинаковых ошибках.

## Используемые технологии

- Python 3.10
- requests
- vk_api
- python-dotenv
- logging
- pytest

## Установка и запуск

Клонировать репозиторий:

```bash
git clone https://github.com/AlexanderProskurin/homework-bot-vk-new.git
cd homework-bot-vk-new
```

Создать виртуальное окружение:

```bash
python -m venv .venv
```

Активировать окружение в Git Bash на Windows:

```bash
source .venv/Scripts/activate
```

Установить зависимости:

```bash
pip install -r requirements.txt
```

Создать файл `.env` в корневой папке проекта и добавить переменные окружения:

```dotenv
PRACTICUM_TOKEN=your_practicum_token
VK_TOKEN=your_vk_community_token
VK_USER_ID=your_vk_user_id
```

Файл `.env` содержит конфиденциальные данные и не должен попадать в GitHub.

Запустить бота:

```bash
python homework.py
```

## Тестирование

Запуск автоматических тестов:

```bash
python -m pytest -v
```

Проверка соответствия PEP 8:

```bash
python -m flake8 homework.py
```

## Логирование

Бот использует стандартный модуль `logging`.

Сообщения выводятся в `sys.stdout` с указанием даты, времени, уровня важности и описания события.
